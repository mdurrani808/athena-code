# Setting up Git LFS

The terrain .dae and other files are stored via Git LFS to reduce load on the repo. To get these files, you will need Git LFS.

To install Git LFS follow the instructions [here](https://git-lfs.com/).

Run `git lfs install`. 

If you have installed Git LFS before cloning, there are no further steps.

If you have already cloned the repo, run `git lfs pull`.
